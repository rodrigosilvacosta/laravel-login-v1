# Sobre o Projeto de Estudos Laravel

Este é um projeto simples de login, no qual, ao executar as seeds, um usuário inicial é criado. A partir desse usuário, é possível realizar o login e cadastrar novos usuários no sistema.

Apesar da simplicidade funcional, o projeto serve como base para estudo e experimentação de boas práticas no desenvolvimento backend.

## Objetivo do Projeto

O foco deste projeto não está na complexidade das funcionalidades, mas sim no aprendizado técnico e na prática de conceitos fundamentais. Os principais objetivos são:

- **Dar os primeiros passos com o framework Laravel**

- Aplicar princípios de **SOLID**

- Praticar conceitos de **DDD** (Domain-Driven Design)

- Escrever e organizar **testes automatizados**

- Configurar e utilizar **Docker**

- Utilizar **Xdebug** integrado ao VS Code para depuração

## Tecnologias e Ferramentas Utilizadas

- PHP

- Laravel

- Docker

- Xdebug

- PHPUnit

- MySQL

## Ambiente de Desenvolvimento

Embora o Laravel ofereça soluções prontas para ambiente de desenvolvimento, como o Laravel Sail, este projeto utiliza um ambiente Docker customizado.
A escolha foi intencional, com o objetivo de aprofundar os conhecimentos sobre Docker, sua configuração e integração com o ecossistema Laravel.

## Considerações Finais


Este projeto faz parte do meu processo de aprendizado contínuo, com foco na consolidação de boas práticas no desenvolvimento backend. Novos conceitos e melhorias poderão ser incorporados futuramente.
